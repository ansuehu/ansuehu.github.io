36 utterances sampled from the six test splits, transcribed by every fine-tuned Whisper model that still exists on disk. Beam 5, max length 225 — the same decoding evaluate_test.py uses.

Two utterances short, two medium and two long per split, drawn at random inside each length band. EusPodcast is split by speaking rate instead: three ordinary segments and three from the under-0.4-words-per-second group whose references account for only part of the speech. Nothing is selected by how well a model did on it.

Highlighting compares each hypothesis to the reference after the same normalization the WER uses: words the model added, words it dropped, words it got wrong. The percentage on each row is that utterance's own WER, so a single bad word in a short reference can read as 50%.
